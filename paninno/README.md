# Paninno

Web de Paninno, paninoteca y focacceria italiana. Next.js 16 + React 19 + TypeScript + Tailwind CSS v4.

```bash
npm install
npm run dev   # http://localhost:3000
```

- Textos, carta, precios, contacto y horarios: `src/lib/site.ts`
- Colores y radios: `src/app/globals.css` (`@theme`)
- Secciones: `src/sections/`
- Fotos: añádelas en `public/images/` y sustituye los `ImagePlaceholder`
- Dirección de diseño y pendientes: `DESIGN.md`
